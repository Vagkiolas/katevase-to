=====================================================================
  KATEVASE TO — ΠΩΣ ΦΤΙΑΧΝΩ ΤΟ .EXE ΜΕ ΤΟ PYINSTALLER
=====================================================================

Αυτό το κάνεις ΚΑΘΕ ΦΟΡΑ που αλλάζεις το katevase_to.py και θες
να βγάλεις καινούριο .exe (π.χ. για τη μαμά ή για τα Releases).


---------------------------------------------------------------------
 ΒΗΜΑ 0 — Μία φορά μόνο (ή αν άλλαξες υπολογιστή / Python)
---------------------------------------------------------------------

Άνοιξε τερματικό (cmd ή PowerShell) και γράψε:

    pip install -U pyinstaller "yt-dlp[default]" imageio-ffmpeg

  - pyinstaller        → φτιάχνει το .exe
  - yt-dlp[default]    → το yt-dlp ΜΑΖΙ με το yt-dlp-ejs (το script που
                         λύνει τους «γρίφους» του YouTube). ΧΩΡΙΣ το
                         [default] το .exe βγάζει «This video is not
                         available» σε πολλά βίντεο!
  - imageio-ffmpeg     → για να δοκιμάζεις MP3 όταν τρέχεις το .py


---------------------------------------------------------------------
 ΒΗΜΑ 1 — Ενημέρωσε το yt-dlp (ΚΑΘΕ ΦΟΡΑ, πριν το χτίσιμο)
---------------------------------------------------------------------

Το .exe κουβαλάει μέσα του όποιο yt-dlp έχεις εκείνη τη στιγμή.
Αν είναι παλιό, θα είναι παλιό και το .exe.

    pip install -U "yt-dlp[default]"


---------------------------------------------------------------------
 ΒΗΜΑ 2 — Πήγαινε στον φάκελο του προγράμματος
---------------------------------------------------------------------

    cd C:\Users\vagki\Desktop\katevase-to


---------------------------------------------------------------------
 ΒΗΜΑ 3 — Χτίσε το .exe  (μία γραμμή, αντέγραψέ τη ΟΛΗ)
---------------------------------------------------------------------

    python -m PyInstaller --noconfirm --onefile --windowed --name Katevase_To --icon icon.ico --add-data "icon.ico;." --collect-all yt_dlp --collect-all yt_dlp_ejs katevase_to.py

(Θέλει το icon.ico μέσα στον φάκελο — δες «ΕΙΚΟΝΙΔΙΟ» πιο κάτω.
 Αν δεν έχεις εικονίδιο, σβήσε από την εντολή τα κομμάτια
 --icon icon.ico   και   --add-data "icon.ico;.")

Τι σημαίνει το καθένα:
  --noconfirm               → σβήνει το παλιό χωρίς να ρωτάει
  --onefile                 → ΕΝΑ μόνο αρχείο .exe
  --windowed                → χωρίς μαύρο παράθυρο κονσόλας
  --name Katevase_To        → το όνομα του .exe
  --icon icon.ico           → το εικονίδιο του ΑΡΧΕΙΟΥ .exe (στον Explorer)
  --add-data "icon.ico;."   → βάζει το icon.ico ΜΕΣΑ στο .exe, για να το
                              δείχνει και το παράθυρο / η γραμμή εργασιών
  --collect-all yt_dlp      → βάζει ΟΛΟ το yt-dlp μέσα
  --collect-all yt_dlp_ejs  → βάζει μέσα και το «λύτη γρίφων» (ΣΗΜΑΝΤΙΚΟ)

Παίρνει ~1-2 λεπτά. Στο τέλος πρέπει να γράφει:
    Build complete! The results are available in: ...\dist

(Γράφουμε «python -m PyInstaller» και όχι σκέτο «pyinstaller», ώστε
 να χρησιμοποιηθεί σίγουρα η ίδια Python που έχει το yt-dlp.)


---------------------------------------------------------------------
 ΒΗΜΑ 4 — Βρες και δοκίμασε το .exe
---------------------------------------------------------------------

Το αρχείο είναι εδώ:

    C:\Users\vagki\Desktop\katevase-to\dist\Katevase_To.exe   (~60 MB)

Δοκίμασέ το πριν το δώσεις:
  1. Διπλό κλικ → ανοίγει το παράθυρο; Γράφει πάνω τη σωστή έκδοση;
  2. Κατέβασε ένα βίντεο MP4 κι ένα MP3.
  3. Δοκίμασε ένα βίντεο που παλιά δεν κατέβαινε.

Οι φάκελοι «build» και «dist» και το αρχείο «Katevase_To.spec» είναι
προσωρινά. ΔΕΝ ανεβαίνουν στο GitHub (τα αγνοεί το .gitignore).

---------------------------------------------------------------------
 ΕΙΚΟΝΙΔΙΟ — πώς βάζω το δικό μου
---------------------------------------------------------------------

Το εικονίδιο ΠΡΕΠΕΙ να λέγεται  icon.ico  και να είναι μέσα στον
φάκελο katevase-to (δίπλα στο katevase_to.py).

Το ίδιο αρχείο χρησιμοποιείται για δύο πράγματα:
  - το εικονίδιο του .exe στον Explorer / στην επιφάνεια εργασίας
  - το εικονίδιο πάνω αριστερά στο παράθυρο και στη γραμμή εργασιών
    (αυτό το δείχνει και όταν τρέχεις το .py από το .bat)

Αν έχεις εικόνα PNG/JPG (όχι .ico), μετάτρεψέ τη:

  Τρόπος Α (με Python — μία φορά: pip install pillow):

    python -c "from PIL import Image; Image.open('logo.png').convert('RGBA').save('icon.ico', sizes=[(16,16),(20,20),(24,24),(32,32),(40,40),(48,48),(64,64),(128,128),(256,256)], bitmap_format='bmp')"

    (βάλε στη θέση του logo.png το όνομα της δικής σου εικόνας)

  Τρόπος Β (χωρίς τίποτα): ανέβασέ τη σε ένα site «png to ico»
    (π.χ. icoconvert.com ή convertico.com) και κατέβασε το .ico.
    Μετονόμασέ το σε icon.ico. ΤΣΕΚΑΡΕ να βγάζει ΟΛΑ τα μεγέθη
    (16, 24, 32, 48, 64, 128, 256), όχι μόνο ένα.

!! ΠΡΟΣΟΧΗ: το .ico πρέπει να έχει ΠΟΛΛΑ μεγέθη μέσα του !!
  Ένα .ico με μόνο 256x256 (όπως πολλά που κατεβαίνουν από το
  ίντερνετ) δείχνει σωστά στο παράθυρο, αλλά στην επιφάνεια
  εργασίας / στον Explorer βγαίνει το γενικό εικονίδιο.
  Αν έχεις ήδη ένα .ico και δεν ξέρεις τι μεγέθη έχει, «φτιάξ' το»
  μ' αυτή την εντολή (το ξανασώζει με όλα τα μεγέθη):

    python -c "from PIL import Image; im=Image.open('icon.ico'); im.size=max(im.info['sizes']); im.load(); im.convert('RGBA').save('icon.ico', sizes=[(16,16),(20,20),(24,24),(32,32),(40,40),(48,48),(64,64),(128,128),(256,256)], bitmap_format='bmp')"

Συμβουλές:
  - Τετράγωνη εικόνα, τουλάχιστον 256x256, ιδανικά με διάφανο φόντο.
  - Απλό σχέδιο — στα 16x16 pixel οι λεπτομέρειες χάνονται.

Αν στην επιφάνεια εργασίας (π.χ. της μαμάς) φαίνεται ακόμα το παλιό:
  1. Σίγουρα έχει το ΚΑΙΝΟΥΡΙΟ .exe; Σβήσε το παλιό και βάλε το
     καινούριο από τον φάκελο dist (ή από τα Releases).
  2. Αν έχει ΣΥΝΤΟΜΕΥΣΗ (shortcut) στην επιφάνεια εργασίας, σβήσ' τη
     και φτιάξε καινούρια: δεξί κλικ στο .exe → «Εμφάνιση
     περισσότερων επιλογών» → «Αποστολή προς» → «Επιφάνεια εργασίας
     (δημιουργία συντόμευσης)». Η παλιά συντόμευση κρατάει το παλιό
     εικονίδιο.
  3. Τα Windows «θυμούνται» τα παλιά εικονίδια (cache). Για να τα
     ξεχάσουν, άνοιξε cmd και γράψε:

         ie4uinit.exe -show

     Αν δεν αλλάξει αμέσως, κάνε επανεκκίνηση τον υπολογιστή.


---------------------------------------------------------------------
 ΑΝ ΚΑΤΙ ΠΑΕΙ ΣΤΡΑΒΑ
---------------------------------------------------------------------
 • «Unable to find ...icon.ico» στο χτίσιμο
     → Δεν υπάρχει icon.ico στον φάκελο. Βάλ' το, ή σβήσε τα
       --icon icon.ico  και  --add-data "icon.ico;."  από την εντολή.


 • «pyinstaller is not recognized» / «No module named PyInstaller»
     → pip install -U pyinstaller

 • Το .exe ανοίγει και κλείνει αμέσως, χωρίς μήνυμα
     → Χτίσε το ξανά ΧΩΡΙΣ το --windowed και τρέξε το από το cmd:
           dist\Katevase_To.exe
       Θα δεις το σφάλμα στην κονσόλα.

 • Το Windows Defender / antivirus λέει ότι είναι ιός
     → Συμβαίνει συχνά με .exe από PyInstaller (ψευδής συναγερμός).
       «Περισσότερες πληροφορίες» → «Εκτέλεση οπωσδήποτε».

 • «This video is not available» στο .exe, ενώ το .py δουλεύει
     → Ξέχασες το  --collect-all yt_dlp_ejs  ή το [default] στο pip.
     → Στον υπολογιστή που τρέχει το .exe πρέπει να υπάρχει Node.js
       (https://nodejs.org). Αν λείπει, το πρόγραμμα το λέει με
       κίτρινη προειδοποίηση.

 • «Permission denied» στο χτίσιμο
     → Το Katevase_To.exe είναι ανοιχτό. Κλείσ' το και ξαναδοκίμασε.
